# Package index

## Accessing traits

Access trait estimates and predictive uncertainty.

- [`download_traits()`](https://fish-trait-network.github.io/fishtraitR/dev/reference/download_traits.md)
  : Download a release of trait predictions
- [`get_traits()`](https://fish-trait-network.github.io/fishtraitR/dev/reference/get_traits.md)
  : Get predicted traits and covariances

## Plot output

Visualize output

- [`plot(`*`<get_traits>`*`)`](https://fish-trait-network.github.io/fishtraitR/dev/reference/plot.get_traits.md)
  : Plot predicted traits and covariances

## Derived quantities

Calculate derived quantities.

- [`get_r()`](https://fish-trait-network.github.io/fishtraitR/dev/reference/get_r.md)
  : Calculate intrinsic growth rate, generation time, and steepness
